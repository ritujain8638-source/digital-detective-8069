# The Digital Detective — Mini System Report (`digital-detective-8069`)

Welcome to my **Digital Detective** independent learning assignment repository. In this project, I investigate how my computer operates from hardware and the operating system to Terminal commands, program execution, number systems, version control with Git/GitHub, and computer networking.

> **Privacy Note:** In accordance with the assignment rules, personal identifiers (such as computer usernames, email addresses, serial numbers, Wi-Fi names, and private IP addresses) have been omitted or replaced with `[redacted]`.

## Workflow & Commit Policy

Each mission in this repository is completed, documented in its own folder, and committed separately in sequential order (`Mission 0` through `Mission 8`) before moving to the next mission.
